# Week 1 — Data Science Project Planning & Strategy

**Deliverable:** Strategic project plan for a hypothetical Python-based customer churn prediction project.

## Scope

The plan defines the business problem, project objectives, data strategy, quality controls, exploratory analysis, feature engineering, model evaluation, governance considerations, and a 33-hour delivery plan.

## Key design choices

- Define churn and the prediction horizon before modelling.
- Protect the workflow from data leakage.
- Use an interpretable baseline before comparing stronger classifiers.
- Evaluate precision, recall, F1, ROC-AUC and PR-AUC where appropriate.
- Translate model outputs into retention priorities rather than treating prediction as the final product.
- Plan monitoring, reproducibility and responsible data use from the beginning.

The report is intentionally framed as a plan. No real business result is claimed at this stage.
