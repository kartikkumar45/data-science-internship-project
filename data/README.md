# Data and Source Notes

This directory is reserved for datasets used by the project.

## Current status

The Week 3 R script expects a local file named `breast_cancer_data.csv`. It is intentionally not included yet because the repository should document the exact source and redistribution conditions before copying a public dataset into a portfolio repository.

## Source

The Week 3 analysis uses the Breast Cancer Wisconsin (Diagnostic) dataset associated with the UCI Machine Learning Repository.

## Reproducibility

Before running the R script, obtain the dataset from its authoritative source and save the required CSV locally using the filename expected by the script. Check the source's current licensing and citation requirements first.

## Privacy

No private, personal, credential, or internship-confidential data should be committed to this repository.
