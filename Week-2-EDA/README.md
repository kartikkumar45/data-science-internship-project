# Week 2 — EDA & Visualization Framework

**Deliverable:** A reusable exploratory data analysis and visualization framework.

## Scope

The framework covers data profiling, quality assessment, univariate, bivariate and multivariate exploration, purposeful visualization, validation of findings, reproducibility and documentation.

## Analytical principles

- Treat exploratory visual patterns as hypotheses rather than proof.
- Investigate missingness, duplicates, inconsistent categories, outliers and data validity before interpretation.
- Distinguish statistical significance from practical business significance.
- Avoid causal claims from observational correlation.
- Check important findings across relevant segments and preprocessing choices.
- Record dataset sources, transformations, assumptions and analytical decisions.

## Connection to modelling

EDA is intended to inform feature engineering, model selection, validation strategy and monitoring. Potential leakage, time dependence, class imbalance, skew and outlier behaviour should be identified before model training.

The report is a framework rather than a dataset-specific findings report because no real dataset was supplied for the assignment.
