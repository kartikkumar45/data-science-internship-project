# Week 3 — Statistical Analysis & Predictive Modelling

This folder is reserved for the Week 3 analytical deliverable and its reproducible implementation.

The project should preserve the distinction between a planned methodology, actual model results, and hypothetical examples. Only validated results from an actual dataset should be presented as model outcomes.

## Intended contents

- Final Week 3 report
- Reproducible R/Python analysis where applicable
- Model evaluation outputs
- Supporting figures
- Environment/package information

## Quality principles

- Establish a baseline before comparing candidate models.
- Keep preprocessing and feature engineering leakage-safe.
- Use evaluation metrics appropriate to the business decision.
- Review errors and model behaviour, not only a single headline score.
- Document assumptions, limitations and reproducibility details.
